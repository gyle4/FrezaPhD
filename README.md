# Лендинг аспирантского проекта

Статический сайт без сборщика и серверной части. Готов для GitHub Pages.

## Локальный просмотр

```bash
python3 -m http.server 8080 --directory aspirantura-site
```

Открыть `http://localhost:8080`.

## Публикация

Содержимое папки можно разместить в отдельном GitHub-репозитории и включить GitHub Pages для ветки `main`, каталога `/ (root)`.

Расчёт стоимости владения:

```text
(цена фрезы + число переточек × цена переточки + резервный комплект)
÷ ресурс в погонных метрах
```

Экономические результаты на сайте помечены как расчётные. Технологические эффекты не представлены как экспериментально доказанные.

## Интерактивные модули

- модель аксиального угла и стоимости владения;
- анатомия кромочного соединения с реалистичным послойным разрезом;
- переключатель «магистратура → аспирантура»;
- карта рациональной области решений;
- матрица будущего эксперимента без вымышленных результатов;
- калькулятор TCO для произвольных фрез;
- NPV, IRR, DPP и сценарный Монте-Карло;
- печатный PDF-отчёт средствами браузера;
- анимация графиков при прокрутке.
